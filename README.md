# Taawun Underpass – 3D Progress Model

Live site: https://nanda51014.github.io/Taawun-Underpass-3D-Progress/

`index.html` is the live model, served by GitHub Pages from the `main` branch.

## Updating the model
1. Replace `index.html` with the new revision. Optionally also add the dated copy, e.g. `Taawun_Underpass_3D_Progress_Model-Rev1-<date>.html`.
2. Commit and push to `main`. The site updates within a minute or two.
